Welcome to Context Clipboard

Let's configure your memory layer and get your IDE connected.

⏱️ Takes ~2 minutes
Step 1 of 5
1

System Check

Verifying your background connections.

🟢 Extension Active 🟡 Checking Server (localhost:8000)...
2

Capture Context

Now I will show you how to use this. Hold Ctrl + Shift and click with your mouse anywhere on the text block below. (Don't worry, you can change the keys later).

"Use this text as a tutorial! You can add information from various tabs without your progress being deleted. Context Clipboard handles deduplication and automatic title resolution behind the scenes."
3

Commit to Memory

Look at the bottom corner of your screen—the context cart icon (📦) is showing what you just read, but haven't committed yet.

Open the cart and click "Send All to Local Memory" to permanently save it to your local database.

4

Retrieve Context

Step 4 is to read from your memory layer. Press Ctrl + Shift + Space to open your Command Palette right here.

Use your arrow keys to select the text you just saved, and press Enter to paste it into the chat box below.

5

Enable in your IDE

Our server has already attempted to inject the MCP connection into your IDE. We just need you to manually activate the tool.

Listening for IDE Connection...
  1. Restart Cursor or VS Code.
  2. Open the AI Chat panel.
  3. Click the Tools (📎) icon.
  4. Find and enable context-clipboard.
  5. Ask the AI: "Review the latest context in my clipboard."
▶ Advanced / Manual Setup

If the automatic installer failed, select your IDE below and paste the exact configuration into your settings:

Cursor / Cline
VS Code / Copilot
{
  "mcpServers": {
    "context-clipboard": {
      "command": "python",
      "args": ["-m", "context_clipboard.server"]
    }
  }
}
{
  "servers": {
    "context-clipboard": {
      "command": "python",
      "args": ["-m", "context_clipboard.server"]
    }
  }
}

⚠️ Ensure you use the absolute path to your virtual environment's python executable.

🎉 You are all set!

Your context is now seamlessly synced across your browser and IDE.
