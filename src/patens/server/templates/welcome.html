Install Server in IDE

If the Context Clipboard server hasn't been added to your IDE yet, select your editor below to see exact instructions on how to link your memory database.

Cursor
VS Code
JetBrains
  1. Open Cursor Settings.
  2. Navigate to Features > MCP Servers.
  3. Click + Add New MCP Server.
  4. Set Type to command.
  5. Copy the JSON below or set Command to your Python/Executable path and Args to --mcp. 
{
  "mcpServers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}

  1. Open your JetBrains IDE.
  2. Ensure you have an AI assistant plugin installed that supports MCP.
  3. Navigate to Settings > Tools > MCP Servers.
  4. Add a new server using the exact absolute path to your executable.
{
  "servers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}

⚠️ Ensure you use the absolute path to your virtual environment's python executable or the Patens.exe file.

6

Activate in Chat

Now that your IDE knows about the server, let's initialize your local workspace files and verify the connection.

  1. Restart your IDE so it loads the new configuration.
  2. Open your AI Chat panel.
  3. Click the Tools (📎) or MCP icon and enable patens.
  4. Ask the AI to initialize your workspace by sending this exact prompt:
Sync my context files.
