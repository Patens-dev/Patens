If the AI says it doesn't recognize the tool, select your editor below for the 1-minute manual setup.

JetBrains
  1. Open Cursor Settings.
  2. Navigate to Features > MCP Servers.
  3. Click + Add New MCP Server.
  4. Set Type to command.
  5. Copy the JSON below or set Command to your path and Args to --mcp. 
{
  "mcpServers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}

  1. Open your JetBrains IDE.
  2. Ensure you have an AI assistant plugin installed that supports MCP.
  3. Navigate to Settings > Tools > MCP Servers.
  4. Add a new server using the exact absolute path to your executable.
{
  "servers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}

⚠️ Ensure you use the absolute path to your virtual environment's python executable or the Patens.exe file.
