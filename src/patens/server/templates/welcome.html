patens auto-configures your IDEs during installation. Let's make sure it is connected.

  1. Restart your IDE completely so it loads the new configuration.
  2. Open your AI Chat panel (Cursor, Copilot, or Cline).
  3. Verify that patens is active:
    • In Cursor: Check the top-right corner of the chat window (or Settings > Features > MCP).
    • In VS Code / Copilot / Cline: Check the tools icon (📎 / ⚡ / MCP) in the bottom corner of the chat panel.
  4. Send this exact prompt to the AI:
Mount Patens context.

Automatic installation failed?

If the AI says it doesn't recognize the tool, select your editor below for the 1-minute manual setup.

Cursor
VS Code
JetBrains
  1. Open Cursor Settings.
  2. Navigate to Features > MCP Servers.
  3. Click + Add New MCP Server.
  4. Set Type to command.
  5. Copy the JSON below or set Command to your path and Args to --mcp.
{
  "mcpServers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}
  1. Open VS Code with an MCP extension (like Cline or Copilot).
  2. Open the extension's MCP Settings.
  3. Edit the configuration JSON file.
  4. Paste the exact configuration below.
{
  "servers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}
  1. Open your JetBrains IDE.
  2. Ensure you have an AI assistant plugin installed that supports MCP.
  3. Navigate to Settings > Tools > MCP Servers.
  4. Add a new server using the exact absolute path to your executable.
{
  "servers": {
    "patens": {
      "type": "stdio",
      "command": "python",
      "args": [
        "--mcp"
      ]
    }
  }
}

⚠️ Ensure you use the absolute path to your virtual environment's python executable or the Patens.exe file.
