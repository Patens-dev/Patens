❌ The Old Copy-Paste Grind

1. Find an auth snippet on StackOverflow.

2. Copy text, switch tabs, paste into Cursor prompt.

3. AI response is missing context. Copy API docs, paste again.

Result: Blown context window, lost focus, and repetitive searching tomorrow.

✨ The Patens Workflow

1. Highlight snippet in Chrome, hit Ctrl+Shift+C.

2. Switch to Cursor and type: "Fix auth using @00_Context_Index.md".

3. AI reads physical local files and generates accurate code instantly.

Result: Zero context switching, offline searchability, perfect prompts.

⚡

Zero-Friction Capture

Highlight text or images on any web page, press Ctrl+Shift+C, and it instantly vectorizes to your local database.

📂

Physical File Mounting

Patens writes Markdown files directly to your workspace's _context/ directory. Works natively with Cursor, Copilot, or Cline.

🔒

100% Private & Local

Powered by local SQLite-vec and FastEmbed. Your code and research never leave your machine. No cloud, no tracking.
