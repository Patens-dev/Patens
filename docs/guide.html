JetBrains Setup: GitHub Copilot + Patens MCP

Replace JetBrains' native AI with GitHub Copilot while giving Copilot access to your Patens local vector memory.

  1. Install GitHub Copilot Plugin in JetBrains:
    Open Settings (Ctrl+Alt+S on Windows/Linux or Cmd+, on macOS) ➔ Plugins ➔ Search GitHub Copilot ➔ Click Install ➔ Restart IDE and sign into your GitHub account.
  2. Install Patens Background Engine:
    Download and run the Microsoft Store App or the .EXE Installer above. This places Patens.exe on your machine at %LOCALAPPDATA%\Programs\Patens\Patens.exe.
  3. Trigger Palette & Stream Memory:
    Highlight research in your browser, press Ctrl+Shift+Space to inspect the command palette, and ask Copilot in JetBrains to synthesize active memory clips autonomously.

Visual Studio 2022 Setup Guide

Configure GitHub Copilot Chat Agent Mode or Visual Studio MCP settings to read Patens memory.

  1. Ensure you are running Visual Studio 2022 v17.14 or later.
  2. Install the Patens background engine via Microsoft Store or .EXE installer above.
  3. Open your Visual Studio solution.
  4. Enable Agent mode in Tools > Options > GitHub > Copilot > Copilot Chat.
  5. Browse and select captured snippets anytime with Ctrl+Shift+Space.
