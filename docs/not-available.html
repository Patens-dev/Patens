💡 Quick Manual Setup Guide

Step 1: How to Load Extension (.zip)
  1. Download and unzip extension.zip to a folder on your computer.
  2. Open a new tab in your browser and copy one of these URLs into the address bar:
    • For Microsoft Edge: copy edge://extensions and press Enter.
    • For Google Chrome: copy chrome://extensions and press Enter.
  3. Click the Developer mode toggle switch (located in the top-right or left sidebar).
  4. Click the Load unpacked button that appears.
  5. Select the unzipped extension folder.
Step 2: How to Install Memory Engine
  1. Option A (VS Code / Cursor): Download patens.vsix, open VS Code, press Ctrl+Shift+X, click the ... menu in the top-right corner of the Extensions panel, and select Install from VSIX.... (No .exe needed!)
  2. Option B (Standalone): Download and launch patens_installer_1.1.0.exe.
🛡️ Windows SmartScreen Warning Note

Because Patens is open-source without an enterprise certificate, Windows SmartScreen may show an "Unknown Publisher" prompt when running the .exe installer.

How to run the installer:
  1. Click the "More info" link on the alert screen.
  2. Click the "Run anyway" button at the bottom.
